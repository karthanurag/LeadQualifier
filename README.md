# LeadQualifier

An AI-powered real estate lead qualification tool that analyzes multiple property leads and classifies them based on their budget, location, and buying potential.

## Features

- Analyze multiple leads at once
- Extract budget and location information
- Score leads from 1–10
- Classify leads as HOT, MEDIUM, or COLD
- Generate a reason for each lead's score
- Uses Google's Gemini AI

## Tech Stack

- Python
- Google Gemini API
- Pydantic
- JSON
- python-dotenv
